## #135 — Granular React Query stale-time and GC policy

**One-file edit:** `src/services/persistentQueryCache.ts`

`createPersistedQueryClient` previously used a single `staleTime: 5 * 60 * 1000`
for every query. It now uses a function that reads `query.meta.category` and
returns a domain-specific value:

| `meta.category` | `staleTime` | Rationale |
|-----------------|-------------|-----------|
| `staff` | 30 min | Near-static hospital directory |
| `records` | 5 min | Immutable after creation; no background refresh needed |
| `appointments` | 30 s | Slots fill and cancel in real time |
| `payments` / `subsidy` | 2 min | Settlement may lag a few seconds |
| _(none / default)_ | 5 min | Safe conservative fallback |

`refetchOnWindowFocus` stays `false` globally. Time-sensitive queries
(e.g. `appointments`) opt back in by passing `refetchOnWindowFocus: true`
directly to their `useQuery` call.

### How to annotate a query

```ts
useQuery({
  queryKey: ['appointments', address],
  queryFn: () => fetchAppointments(address, 'doctor'),
  meta: { category: 'appointments' },     // ← add this
  refetchOnWindowFocus: true,             // ← opt-in for live slots
});
```

```ts
useQuery({
  queryKey: ['staff', hospitalAddress],
  queryFn: () => fetchStaff(hospitalAddress),
  meta: { category: 'staff' },            // ← 30-minute stale window
});
```

```ts
useQuery({
  queryKey: ['records', patientAddress],
  queryFn: () => fetchRecords(patientAddress),
  meta: { category: 'records' },          // ← 5-minute stale window, no focus refetch
});
```

## #136 — Delta sync for low-bandwidth rural clinical sync

**Area:** `src/services/api.service.ts`, `src/lib/`

### Still to implement

Create `src/lib/deltaSync.ts`:

```ts
import { compare, applyOperation } from 'fast-json-patch';
import { sha256 } from './crypto';   // existing crypto helper

export async function buildPatch(baseline: unknown, head: unknown) {
  const patch = compare(baseline as object, head as object);
  const preHash  = await sha256(JSON.stringify(baseline));
  const postHash = await sha256(JSON.stringify(head));
  return { patch, preHash, postHash };
}

export async function applyAndVerify(
  baseline: unknown,
  patch: Operation[],
  expectedPostHash: string,
): Promise<unknown> {
  let doc = structuredClone(baseline);
  for (const op of patch) {
    applyOperation(doc, op, true);   // validate = true
  }
  const actualHash = await sha256(JSON.stringify(doc));
  if (actualHash !== expectedPostHash) {
    throw new Error('Delta integrity check failed — falling back to full sync');
  }
  return doc;
}
```

Wire into `api.service.ts`:
- `syncRecord(recordId, baseline, head)`: attempt delta; if `applyAndVerify`
  throws (corrupt/out-of-order), fall back to `PUT /records/:id` with the full document.
- Add `X-Sync-Mode: delta` header when patching so the server can log coverage.

**Fallback trigger:** any of:
- `patch` contains more than 200 operations (indicates full replacement is cheaper).
- `preHash` returned by the server does not match the client baseline digest.
- `applyAndVerify` throws.
